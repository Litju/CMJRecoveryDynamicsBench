# Gate7-native evaluation contract, version 1

This separate research contract uses the source-defined Gate7 target keys as **innovations**, not the generic canonical `OutcomeVariable` labels. It creates no crosswalk and does not redefine the historical benchmark. The target-authority audit remains in force: neither canonical crosswalk nor the exact materialization of every historical final-split value is established.

| Native target key | Source-contract measurement | Innovation unit |
| --- | --- | --- |
| `relative_mean_concentric_force` | Time-mean gross vertical ground-reaction force from concentric onset through takeoff, normalized by explicit system mass | N/kg |
| `relative_concentric_net_impulse` | Integral of vertical force minus system mass times gravity over the concentric interval, normalized by the same system mass | m/s |

The authenticated mechanics authority specifies interpolated event boundaries, in-contact integration and exclusion of post-takeoff samples. The source-contract criterion is the arithmetic mean of three valid trials; its pre-index baseline is the arithmetic mean of the two latest qualifying valid assessments in the inclusive 24–240-hour pre-origin interval. Innovations are additive, baseline-relative outputs. The source-level relationship does not establish that subtracting separately serialized historical values exactly reproduces the stored innovation. Original model outputs use an identity transform; training-only cell scales are separate from system-mass normalization.

The native query contract identifies dataset, participant, origin, query and input, and fixes H72 to nominal 72 hours and window 66–78 hours, or D7 to nominal 168 hours and window 156–180 hours. It records two distinct qualifying baseline assessment identities and offsets with three valid trials each. Queries sharing an origin must preserve the same baseline identities and offsets across horizons. Both targets for a query must reference the same target assessment identity and time within the horizon window; that target assessment must differ from both baseline assessments. Prediction and observation identities, target keys and native units must match exactly; duplicates, missing target/horizon cells, overlapping participant splits and participants absent from the test split are rejected. The record checks cannot independently prove that the supplied baselines were the latest qualifying assessments, that an input was available at origin, or that identifiers refer to the same real observations; establish those facts from the authenticated source and complete history.

`metrics.native_research.NATIVE_SOURCE_V1` fixes these source-contract definitions. `NativeAuthority` requires an operator-supplied reference and a SHA-256 pin matching an independently supplied expected authority. Matching strings or digests establishes neither provenance nor permission: a qualified operator must authenticate the source, identity associations and data rights externally. A structurally valid record is not evidence of eligibility, source integrity or clinical validity.

`synthetic_native_rmse_v1` routes paired records to four native target/horizon cells and returns native-unit RMSE for explicitly declared synthetic test data only. The synthetic label is a caller assertion, not proof that a dataset is synthetic. This is a new uncalibrated research metric: it does not normalize by historical cell scales, use benchmark floor or calibration parameters, select a model, or reproduce a historical benchmark score. The implementation does not authorize empirical scoring. Independent cohort access, original target and input authority, participant separation, and permission to disclose results must be established before any empirical evaluation; an appropriately authorized evaluation path would require separate review.

Synthetic tests use invented identities and values only. The unlabeled public Gate7 observation fixture is an inference fixture, not a predictive-performance test set. No empirical data were scored to implement this contract.
