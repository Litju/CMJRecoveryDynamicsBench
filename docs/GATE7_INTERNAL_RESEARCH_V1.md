# Native research engineering package, version 1

This package prepares internal research tooling. It does not qualify an independent cohort, authorize empirical execution or establish predictive performance. Recovered model loaders, checkpoint restrictions, historical CPU/CUDA findings and release identities remain unchanged. Investigator and partner documents, detailed evidence receipts and experimental outputs are maintained outside the public repository.

## Executable components

| Component | Purpose | Admission boundary |
| --- | --- | --- |
| `observations.native_mechanics` | Native force-time arithmetic and five deterministic schedule-basis values | Requires authenticated event/system-mass inputs; does not detect empirical events or grant permission |
| `observations.native_preflight` | Metadata, structural, scientific-authority, independence and use/disclosure stages; optional aggregate assessment | A valid file cannot establish real-world authority; empirical execution remains blocked |
| `metrics.native_analysis` | Four-cell native errors, frozen training constants, paired uncertainty, Holm and locked decisions | Synthetic-only, with independently pinned input-bound admission and explicit plan |
| `metrics.native_rehearsal` | New invented labeled engineering fixture, all 18 candidate/repeat combinations and corruptions | Invented predictions test arithmetic; they do not measure recovered-model performance |
| Local Research Lab | Existing loopback inference with explicit observation/model/basis grants | No public checkpoint endpoint; default synthetic weights and independent original-checkpoint grants |

Run the full deterministic rehearsal with:

```sh
python -m cmj_recovery_dynamics.metrics.native_rehearsal --synthetic-rehearsal
```

The receipt records the synthetic declaration, source/plan/input identities, staged admission, counts, methods, four separate cells, per-repeat/family metrics and paired comparisons, bootstrap and test conventions, refusal controls and explicit decisions. The six-participant engineering example can correctly fail its hypothetical Holm criterion. Do not alter its p-values or invent more favorable thresholds to call the software successful.

Read `GATE7_NATIVE_ANALYSIS_V1.md` for weighting, repeats, uncertainty and decision semantics; `GATE7_NATIVE_MEASUREMENT_V1.md` and `GATE7_NATIVE_DEPENDENCIES_V1.json` for source mechanics and the basis graph; and `NATIVE_DATASET_SCHEMA_V1.json` / `NATIVE_PREFLIGHT_V1.md` for admission and steward-side aggregate assessment.

## Qualification

Source and installed-wheel tests include new native mechanics, analysis, preflight and the end-to-end rehearsal. Deterministic numerical checks include a separately authored row-expansion reference with unequal participant cluster sizes and repeated cluster draws. Detailed private verification additionally compares the reconstructed constructors with isolated authenticated original arithmetic on invented inputs only. A digest verifies byte identity, not consent or scientific validity.

The browser qualification service `tests/research_lab_service.py` uses the existing loopback backend, invented public observations and synthetic weights. Only its first origin receives a source-constructed synthetic basis grant; other origins retain refusal behavior. It registers no original checkpoints. With an operator-generated local token, run this service for the Research Lab Playwright live tests. CI exercises every M0–M8/r0–r1 route, both horizon identities, units, provenance, execution identities and basis/original-checkpoint refusals on desktop and mobile. Existing tests cover keyboard operation, small-value precision, wrong-response identity, outages, cancellation, timeouts and automatic accessibility checks.

Source tests, Ruff, strict Pyright, wheel/sdist builds, installed-wheel execution, browser checks and disclosure scans must pass for a qualified change. Scientific source pins, machine locators, original configurations/weights and participant records must not enter public code, bundles, logs or archives. No scoring receipt or cohort record belongs in the public distribution.

## Investigator decisions and pending external gates

A real study still needs an independent labeled cohort, steward-confirmed measurement/input compatibility, identity separation, signed data-use and result-disclosure authority, ethics determination where required and a justified locked analysis plan. Native-unit improvement margins, harm/bias bounds, minimum group counts, power assumptions and the primary candidate are investigator decisions; the public rehearsal's values are hypothetical only. Prospective collection must retain origin-known schedules and full history rather than invent missing records.

Source inspection resolves deterministic basis construction from public exposure times/durations and the original fixed constants. It does not resolve an empirical instrument's event detector or authenticate a steward's archived timing. Exact historical final-split materialization and generic canonical target crosswalks remain unresolved. No historical labels or calibrated scores are recomputed.

**SCREEN_READER_ACCEPTANCE_PENDING** remains separate. Follow `GATE7_NVDA_ACCEPTANCE_V1.md` for an actual Windows/NVDA session; automated checks and an accessibility tree cannot substitute for a human assistive-technology acceptance record.
